# 政策知识库 · RAG 政策问答系统

一个面向政策文件的知识问答系统：把分散在多层级（全国 / 省 / 市）的政策文档结构化为知识块，基于检索增强生成（RAG）回答用户问题，并对每一条回答强制标注来源。

> 说明：这是一个 **RAG 问答系统**，不是自主智能体（无规划循环、无工具自主选择、无跨轮记忆）。

## 功能

- 政策文档导入与知识块切分，支持多层级（全国 / 省级 / 市级）组织
- 混合检索：BM25 + 向量召回，Top20 召回后重排取 Top5
- 强约束提示词：仅依据检索材料作答、每句带 `[n]` 引用并映射回真实知识块、材料不足主动拒答、屏蔽失效文件
- 冲突检测：时效 / 位阶 / 适用主体 / 地域 / 同一事项口径
- 用户与管理端：登录鉴权、知识库管理、问答记录
- 优雅降级：未配置大模型 Key 时自动切换为「原文摘录模式」，不影响主流程

## 技术栈

- 后端：Python · FastAPI · SQLAlchemy（SQLite / MySQL 双模式）
- 前端：Vue3 · Element Plus（纯静态，无构建）
- 检索：numpy 向量索引（512 维特征哈希）+ 自实现 BM25
- 大模型：DeepSeek（OpenAI 兼容接口）

## 运行

```bash
pip install -r requirements.txt
python run.py
```

默认使用本地 SQLite，零配置启动。接入大模型需设置环境变量：

```bash
export DEEPSEEK_API_KEY=your_key
```

数据库、端口等均可通过环境变量覆盖，详见 `app/core/config.py`。
